# ReNew

ReNew is a simple, responsive front-end web project built using **HTML**, **CSS**, and **JavaScript**.  
It provides a modern layout for an e-commerce style website including pages such as Home, Products, About, and user account pages like Sign In and Sign Up.

## 🚀 Features

- **Responsive Design:** Works on desktop and mobile screens.
- **Navigation Bar:** Easy access to all main pages.
- **Multiple Pages:**  
  - Home  
  - Products  
  - About Us  
  - My Order  
  - Payment  
  - Donation pages  
  - Signin / Signup pages
- **Interactive UI:** JavaScript used for interactive elements across the site.
- **Styled UI:** Custom styles using CSS to make the layout clean and modern.

## 🧱 Tech Stack

This project was built with:

- **HTML** – for content structure  
- **CSS** – for styling and layout  
- **JavaScript** – for dynamic page behavior

## 📌 How to Use

1. Clone the repository  
2. Open the `index.html` file in your browser  
3. Navigate between pages using the menu

## ❤️ Why ReNew?

ReNew is designed to be a starting web project for beginners learning front-end development, or as a template for small e-commerce style websites. It’s clean, easy to understand, and simple to expand.
